# Contributing

Pull requests are welcome from vouched contributors. If you're not yet vouched,
open a discussion in the [Discussions tab](../../discussions) describing your
proposed contribution, and a maintainer will vouch you by commenting `!vouch`
on your discussion.

## Bots and automated contributors

Bots (accounts ending with `[bot]`) and collaborators with write access are
automatically allowed and do not need to be vouched. This includes:

- `renovate[bot]` — dependency updates
- `chronova-agent[bot]` — CI/automation
- `google-labs-jules[bot]` — automated contributions

## How to get vouched

1. Open a discussion in the **Discussions** tab
2. Describe what you'd like to contribute
3. A maintainer will comment `!vouch` to add you to the vouched list
4. You can then open pull requests normally

## Vouch commands (maintainers only)

- `!vouch` — vouch the discussion author
- `!vouch @user` — vouch a specific user
- `!denounce @user` — block a user from contributing
- `!unvouch @user` — remove a user from the vouched list
